App-local DLL deployment is supported; client installation of the VC runtime
is not required when the complete required DLL closure is supplied. Preserve
Microsoft DLL bytes unchanged. Only the release x64 files pinned in
vc-runtime-manifest.json may be staged, with their original installer/CAB
provenance, file-version and PE/loaded-module checks. No System32 substitution.

App-local components are not serviced independently by Windows Update. The
distributor must track Microsoft runtime security updates, review updated pins,
rebuild, rerun the full acceptance suite and redistribute updated application
bytes. Static CRT builds also need rebuilding to incorporate runtime updates.

Earlier project builds unnecessarily coupled DLL staging to downloads of two
specific historical DOCX files. Their identities are retained as historical
metadata only. This build does not fetch, read or substitute those documents.
